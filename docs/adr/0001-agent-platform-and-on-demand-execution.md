# 从用户执行工作区转向可创建、发布和协作的智能体平台

2026-10-27，用户提出将 OrchMesh 的产品中心从“每位用户拥有长期 Shell/代码执行环境”调整为“通过自然语言创建智能体，支持发布及自主选择协作者”。长期助手所需的会话与用户记忆应与执行环境的存活周期分离；需要执行代码时按需分配临时沙盒，不再把每用户常驻容器作为产品前提。

这是需求澄清中的方向记录，尚非可实施规格。已确认首版不提供预编排，只支持用户发起的自主协作；发布版本与任务执行分离，私人记忆不随发布共享。首版面向受邀用户，只发现本平台智能体，协作者调用无需逐次确认；平台承担模型费用且暂不设用量额度，上传文件与成果独立保存。首版必须支持任务重启恢复；运行时、沙盒及具体恢复方案仍待核查，不据此预先决定更换 DSH。现有代码暂不改动。

完整已确认范围与开放问题见 [需求规格](../product/agent-platform-discovery.md)。

技术提案现已整理为[首版架构](../architecture/agent-platform-v1.md)与[迁移计划](../development/agent-platform-migration.md)。具体组件仍须通过接入和恢复实验；本 ADR 仍为 proposed，不表示应用已迁移。
