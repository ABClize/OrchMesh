# Codex 浏览器验收

浏览器操作、页面调试和截图使用 Codex 内置浏览器，不为这些功能安装项目级 Playwright、浏览器 CLI 或额外 skill。pytest 与 Vitest 保留，用于可重复的代码行为检查。

## 默认：真实环境验收

用户已授权后续端到端验收使用项目管理员账号和 `.env` 配置的真实模型。启动 `make run`，通过 Codex 内置浏览器检查登录、回复、流式输出、停止及刷新恢复。凭据仅从本机配置读取，不输出到工具结果或截图；验收对话明确标记用途，不修改或删除原有数据。模拟服务只用于确定性边界测试，不能替代最终验收。

## 可选：启动可重复的模拟测试服务

从仓库根目录执行：

```bash
npm --prefix apps/web run build
uv run --directory apps/server uvicorn browser_app:app --app-dir tests --host 127.0.0.1 --port 8765
```

这个测试入口使用临时数据库和确定性 RPC 替身，不能作为生产入口。仅监听本机。测试账号 `browser@example.com`，密码 `test-password-only-123`。不访问外部模型或个人凭据；测试服务退出后临时数据清理。

## 在 Codex 内置浏览器中操作

1. 打开 `http://127.0.0.1:8765`，输入测试账号并登录。
2. 创建新对话，发送 `slow`，确认内容逐步出现并显示停止按钮。
3. 刷新页面，打开同一对话，确认能看到后台执行继续输出。
4. 点击停止，确认出现停止提示，按钮恢复为发送状态。
5. 发送 `hello`，确认能正常完成新一轮，旧历史仍可查看。
6. 在同源第二个标签页验证登录保持；退出后两个标签页均清除界面，刷新后仍显示登录界面。退出仅清除本地 JWT，不撤销其他浏览器的 JWT，也不终止 Pi 任务。
7. 检查页面布局和浏览器错误，必要时保存截图；结束后停止本次启动的测试服务。

记录实际执行步骤、结果和未验收项。这套操作依赖 Codex 会话，不是无人值守 CI 浏览器回归。真实 Pi 容器用独立 pytest 验证，外部真实模型还需要配置项目凭据后另行验收。
