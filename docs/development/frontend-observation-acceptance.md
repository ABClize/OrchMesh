# 前端协作工作空间实施与验收

日期：2026-10-27。依据：[设计方案](../product/frontend-experience-design.md)、[观测接口契约](../api/multi-agent-observation.md)。

## 已实现

- 对话 / 协作双视图；切换不卸载主聊天 runtime，保留输入草稿。
- 共享的一条对话 graph 流，按根调用在前端从服务端身份记录筛选并重新聚合。旧运行范围不会被新状态快照替换为最新运行。
- React Flow + Dagre 调用图及等价列表。双向调用分开走线，自调用保留自环；节点显示混合活动计数，边按真实调用计数。状态刷新不重新布局，详情面板宽度改变时保留视口中心。
- Agent / 边 → 调用列表 → 独立调用详情。仅可见详情订阅任务日志，切换和退出取消请求。节点 ID 从不当作 task ID。
- 独立只读 assistant-ui runtime 展示任务输出；任务提问复用现有 RequestCard；文件复用现有授权、预览及下载。不同批次独立提交，错误保留回答，归档和历史对话禁止界面作答。
- 执行记录按真实 seq 和轮次展示步骤、工具与结果；正文和 JSON 均按文本安全渲染。没有工具结果不判成功；不虚构进度、费用或恢复次数。
- 任务历史初始分页读取与 SSE 续读使用 next_after / Last-Event-ID；空事件页也推进游标，重连去重，done 关闭流，unavailable 退避并保留数据，401 与旧令牌竞态沿用会话保护。
- 智能体库、知识与记忆独立页面，草稿编辑独立组件；保留原有发布确认。知识加载失败不能误将草稿知识绑定清空。
- 材料上传移到输入框附近，客户端校验 20 MiB；文件面板分任务材料与交付成果，历史目录为次级入口。查看文件时不叠加第二个执行详情面板。
- 小于 1100 px 时详情替换图区域，小于 768 px 使用列表。长任务目标可展开，按钮换行，文件使用现有移动端 Sheet。

主要模块：`apps/web/src/features/observation/` 分离数据模型、SSE、hooks、图、选择工作空间、调用详情、问题和记录；`features/platform/` 分离目录、编辑、评论和知识记忆；`features/workspace/ConversationFiles.tsx` 组合现有文件能力。生成 API 类型与执行所有权未改变。

## 2026-10-27 Trace Waterfall 桌面版

执行记录替换为共用时间轴的轮次→步骤→工具瀑布图，消息/重试等未配对事件保留为时间点。参考 Affect UI 的紧凑瀑布布局和 AgentPrism 的层级记录检查方式；未复制 Pro 源码、未新增依赖。通用 `components/trace-waterfall` 只接收时间段与详情插槽，`features/observation/traceModel.ts` 负责真实事件配对；复用 shadcn Button、AnimatedDisclosure、AnimatedValue、调用树的语义配色与 220ms 动效。

- 工具按 callId 配对，支持同名重叠调用；重复 SSE 事件去重。缺失结束、未知时间、孤立结果保留可见，不虚构成功或耗时。已闭合祖先下的未结束子项不继续播放执行动画。
- 实时且任务活跃时更新已过时间；执行与等待分别控制动画。完成/断线停止实时外推，卸载清理时钟，减少动画偏好禁用动效。原始输入与工具结果按需展开。
